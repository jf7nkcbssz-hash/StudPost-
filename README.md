# Flux

An interactive flow-field laboratory. Paint with motion.

## Aprilo in Kodo

1. Estrai lo ZIP nell'app File.
2. Apri in Kodo il file index.html nella cartella principale di questo progetto.
3. Avvia l'anteprima HTML. CSS e JavaScript sono inclusi nel file: non serve rete.
4. Per lavorare su tre file distinti usa invece source/index.html, mantenendo
   style.css e app.js nella stessa cartella source.

La versione principale e quella source sono due copie indipendenti.
Se modifichi una, l'altra non si aggiorna automaticamente.

## Interazioni da provare

- Passa da Wave field a Vortex o Crosscurrent.
- Cambia palette, velocità e numero delle particelle.
- Muovi il puntatore o tocca il campo per influenzare il movimento.
- Metti in pausa per uno screenshot oppure esporta il canvas in PNG.

## Ripresa suggerita

Apri Vortex, passa da Plasma a Ember e sposta un dito sul campo. Per lo screenshot premi Pause quando la composizione ti piace.

## Prompt breve per l'AI di Kodo

Change the default palette in CONFIG from plasma to ember. Update the selected palette button so it matches the new default.
